# eFootball My League Manager

スマホのブラウザでも使える、FC Barcelona用のマイリーグ記録アプリです。

## 機能
- 2026/27シーズンのラ・リーガ20クラブを初期登録
- FC Barcelonaの試合結果を登録
- 得点者・アシストを1得点ごとに記録
- 入力した試合から勝敗・勝点・得失点差を集計
- 得点ランキング・アシストランキング
- チームの追加・削除、試合履歴の削除

## 起動方法（Windows）
1. Pythonをインストール
2. このフォルダでターミナル（コマンドプロンプト）を開く
3. 次を実行

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

表示されたURLをPCで開きます。スマホから同じWi-Fi経由で開く場合は、次のように起動します。

```bash
python -m streamlit run app.py --server.address 0.0.0.0
```

PCのローカルIPアドレスとポート8501を使って、スマホのブラウザからアクセスします。
PCとスマホは同じWi-Fiに接続してください。ファイアウォールの許可が必要な場合があります。

## データ保存について
試合・チーム・得点イベントは、同じフォルダ内の `my_league.db` に保存されます。
この初版はローカル保存です。PCで起動したままにする必要があります。
インターネット上に公開してスマホからいつでも使う場合は、次の段階でクラウドDBを接続するのがおすすめです。

## 注意
- 初期チーム一覧はLALIGA公式の2026/27クラブ一覧をもとにしています。
- 順位表は登録されたFC Barcelonaの試合だけを集計します。他クラブ同士の試合は登録されないため、リーグ全体の完全な順位表ではありません。
- 得点・アシストは手入力です。eFootballとの自動連携はありません。
